## 1. Тон коммуникации

### Основной принцип
Алло — это **помощник**, а не IT-система. Тон — **дружелюбный, заботливый, без пафоса**. Как разговорчивый администратор, который помогает салону работать лучше.

### Голос в интерфейсе

| Сценарий | Пример |
|----------|--------|
| Приветствие | «Добрый день! Я Алло, голосовой секретарь вашего салона» |
| Onboarding | «Давайте подключим ваш салон за пару шагов. Никакой магии, всё просто» |
| Пустой список | «Звонков пока нет — значит, Алло ещё не работал. Как только появятся, вы увидите их здесь» |
| Ошибка | «Что-то пошло не так. Попробуйте ещё раз — обычно помогает» |
| Успех | «Всё готово! Алло принимает звонки» |

### Чего избегать
- ❌ «Телефония», «SIP-транк», «VoIP-шлюз» (заменять на «номер телефона», «подключение»)
- ❌ «AI», «нейросеть», «искусственный интеллект» (заменять на «Алло», «секретарь», «помощник»)
- ❌ «Деплой», «интеграция», «конфигурация»
- ✅ «Настройка», «подключение», «готово»

### Форма обращения
- На «ты» (сайты и интерфейсы на «ты» — стандарт рунета)
- «Подключи свой салон», «Посмотри статистику»
- Но не фамильярно — без «приветик», «окей», «кек»

### Эмодзи
- В интерфейсе: ✅ ❌ ⚠️ 🎉 (только для статусов, не декоративно)
- В Telegram-боте: 🏪 📞 ✂️ 📅 🎯 (умеренно, для визуальной группировки)

## 2. Дизайн-система

### 2.1 Цветовая палитра

#### Светлая тема

| Роль | HEX | Использование |
|------|-----|---------------|
| **Primary 500** | `#8B5CF6` | Основные кнопки, активные ссылки, акценты |
| **Primary 100** | `#EDE9FE` | Фон для выделенных блоков, бейджей |
| **Primary 700** | `#6D28D9` | Hover на кнопках, активные состояния |
| **Primary 50** | `#F5F3FF` | Очень лёгкий фон, skeleton loading |
| **Surface BG** | `#FAFAFA` | Основной фон страницы |
| **Card BG** | `#FFFFFF` | Фон карточек, модалок |
| **Text Primary** | `#1A1A2E` | Основной текст (заголовки, body) |
| **Text Secondary** | `#6B7280` | Вторичный текст, подписи |
| **Text Tertiary** | `#9CA3AF` | Placeholder, неактивные элементы |
| **Border** | `#E5E7EB` | Границы карточек, разделители |
| **Success** | `#10B981` | Успешные операции, статус "активно" |
| **Warning** | `#F59E0B` | Предупреждения |
| **Error** | `#EF4444` | Ошибки, критические уведомления |
| **Error BG** | `#FEF2F2` | Фон для сообщений об ошибке |

**Проверка контрастности:**
- `#1A1A2E` on `#FAFAFA` → contrast ratio 17.4:1 ✅ (AAA)
- `#6B7280` on `#FAFAFA` → contrast ratio 6.9:1 ✅ (AA large, AA normal)
- `#FFFFFF` on `#8B5CF6` → contrast ratio 5.1:1 ✅ (AA)
- `#1A1A2E` on `#EDE9FE` → contrast ratio 10.3:1 ✅ (AAA)

#### Тёмная тема

| Роль | HEX | Использование |
|------|-----|---------------|
| **Primary 400** | `#A78BFA` | Основные кнопки, акценты (на тёмном фоне) |
| **Surface BG** | `#0F0F23` | Основной фон |
| **Card BG** | `#1A1A35` | Фон карточек |
| **Text Primary** | `#F3F4F6` | Основной текст |
| **Text Secondary** | `#9CA3AF` | Вторичный текст |
| **Border** | `#2D2D4A` | Границы |
| Остальные — те же, что в светлой |

#### Цветовая философия
Фиолетовый выбран не случайно:
- Не такой «медицинский» как синий
- Не такой «женский-розовый» (салоны и так розовые)
- Ассоциируется с творчеством, интеллектом, спокойствием
- Хорошо читается и в тёмной, и в светлой теме
- Не похож на конкурентов (обычно синий или зелёный)

#### Шрифты

- **Fallback:** -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif

### 2.3 Система отступов

**Base unit: 4px**

```
4  →  xxs
8  →  xs
12 →  sm
16 →  md
20 →  lg
24 →  xl
32 →  2xl
40 →  3xl
48 →  4xl
64 →  5xl
```

**Применение:**
- Отступы между карточками: 16px (mobile), 24px (desktop)
- Padding внутри карточки: 16px (mobile), 20px (desktop)
- Отступ между секциями: 32px
- Горизонтальные отступы в мобильном лейауте: 16px

### 2.4 Border Radius

| Уровень | Значение | Использование |
|---------|----------|---------------|
| **none** | 0px | — |
| **sm** | 6px | Инпуты, маленькие элементы |
| **md** | 12px | Карточки, модалки |
| **lg** | 16px | Крупные карточки, страницы |
| **xl** | 20px | Модалки на мобильных |
| **pill** | 9999px | Аватарки, чипсы, бейджи |

### 2.5 Shadows

| Уровень | Значение |
|---------|----------|
| **sm** | `0 1px 2px rgba(0,0,0,0.05)` |
| **md** | `0 4px 6px -1px rgba(0,0,0,0.07), 0 2px 4px -2px rgba(0,0,0,0.05)` |
| **lg** | `0 10px 15px -3px rgba(0,0,0,0.08), 0 4px 6px -4px rgba(0,0,0,0.04)` |
| **modal** | `0 20px 25px -5px rgba(0,0,0,0.12), 0 8px 10px -6px rgba(0,0,0,0.06)` |

### 2.6 Иконки

- **Библиотека:** Lucide Icons (opensource, единый стиль, русские аналоги)
- **Размеры:** 16px (inline), 20px (кнопки), 24px (навигация), 32px (пустые состояния)
- **Стиль:** Outline, stroke-width 1.5–2

### 2.7 Компоненты

#### Кнопки

| Вариант | Бэкграунд | Текст | Hover | Disabled |
|---------|-----------|-------|-------|----------|
| **Primary** | Primary 500 | White | Primary 700 | 40% opacity |
| **Secondary** | Card BG, border Primary 500 | Primary 500 | Primary 50 | 40% opacity |
| **Ghost** | Transparent | Text Primary | Gray 50 | 40% opacity |
| **Danger** | Error | White | Darker red | 40% opacity |

**Размеры:**
- Large: 48px height, padding 16-24px
- Medium: 40px height, padding 12-20px
- Small: 32px height, padding 8-12px

**Touch target (mobile):** минимум 44×44px (WCAG 2.1)

#### Инпуты

- Height: 44px (mobile), 40px (desktop)
- Border: 1.5px solid Border
- Focus: 2px solid Primary 500 + box-shadow
- Label: над инпутом, 14px/500, margin-bottom 6px
- Helper text: под инпутом, 12px/400, Text Tertiary
- Error: border Error + helper text Error

#### Карточки

- Бэкграунд: Card BG
- Border: 1px solid Border (или shadow md вместо border)
- Radius: md (12px)
- Padding: 16px (mobile), 20px (desktop)
- Могут быть кликабельными (cursor pointer + hover elevation)

#### Бейджи / Чипсы

| Тип | Бэкграунд | Текст | Пример |
|-----|-----------|-------|--------|
| **Success** | Green 100 | Green 700 | «Активно» |
| **Warning** | Amber 100 | Amber 700 | «Ожидает» |
| **Error** | Red 100 | Red 700 | «Ошибка» |
| **Neutral** | Gray 100 | Gray 700 | «Выключено» |
| **Primary** | Primary 100 | Primary 700 | «Новое» |

#### Таблица / Список звонков

- Чередование строк: Card BG / Surface BG (каждая вторая строка)
- Hover: Primary 50
- На мобильных: карточки вместо таблицы (stacked layout)

#### Bottom Sheet / Модалка

- Mobile: Bottom Sheet (снизу, drag to dismiss)
- Desktop: Modal (центр, overlay)
- Overlay: rgba(0,0,0,0.4), backdrop-filter blur(4px)
- Close: кнопка × в правом верхнем углу (на desktop) или свайп вниз (на mobile)

#### Скелетон / Skeleton Loader

- Бэкграунд: Gradient от Surface BG до Gray 100
- Анимация: shimmer (движение градиента слева направо за 1.5s)
- Формы: соответствуют конечным блокам (прямоугольник для текста, круг для аватарки)

#### Тосты / Toast Notifications

- Позиция: top-right (desktop), top-center (mobile)
- Duration: 4 секунды
- Типы: success (зелёный маркер), error (красный), info (Primary)
- Dismiss: кнопка × или через 4s
- Стек: до 3 тостов одновременно

## 3. Admin Panel — Структура и навигация

### 3.1 Layout

```
┌─────────────────────────────────┐
│  Top Bar                        │
│  ← Алло    [салон]    [👤]      │
├──────────────────┬──────────────┤
│  Sidebar (240px) │  Content     │
│                  │              │
│  📊 Дашборд      │              │
│  📞 Звонки       │              │
```

**Desktop (≥1024px):** Sidebar всегда видна, контент справа
**Tablet (768-1023px):** Sidebar сворачивается в иконки (коллапс)
**Mobile (<768px):** Sidebar скрыта, открывается свайпом/hamburger

### 3.2 Top Bar

- Слева: логотип «Алло» (логотип + название)
- Центр: название текущего раздела (на мобильных)
- Справа: название салона (dropdown — только если несколько салонов, MVP — просто текст), аватарка владельца

### 3.3 Sidebar

**Пункты навигации:**
1. **Дашборд** — 📊 (LayoutDashboard icon)
2. **Звонки** — 📞 (Phone icon)
3. **Записи** — ✂️ (Scissors icon, или Calendar icon)
4. **Настройки** — ⚙️ (Settings icon)

**Нижняя часть:**
- Разделитель
- Статус «Алло активен» с зелёной точкой (или «Выключен» с серой)

**Активный пункт:** Primary 100 background + Primary 500 text + 3px left border Primary 500

## 5. Telegram-бот

### 5.1 Общий принцип

Бот — **компаньон**, а не ещё один интерфейс. Он не дублирует весь админ-панель, а даёт самое важное — **уведомления** и **быстрые действия**.

### 5.2 Команды

| Команда | Описание | Ответ |
|---------|----------|-------|
| `/start` | Приветствие | Привет! Я Алло, бот-помощник твоего салона |
| `/status` | Статус системы | 🟢 Алло активен. Сегодня: 5 звонков, 3 записи |
| `/bookings` | Записи на сегодня | Список записей на сегодня (максимум 5, кнопка «Все» → ссылка на админку) |
| `/calls` | Последние звонки | 3 последних звонка с результатом |
| `/settings` | Быстрые настройки | Приветствие / Выключить Алло / Сменить тариф |

### 5.3 Формат уведомлений

#### Новая запись
```
🏪 *Новая запись!*

Мария записалась на стрижку
🗓 15 мая в 14:00
✂️ Мастер: Елена

[Посмотреть в админке]
```

#### Эскалация (звонок переведён на владельца)
```
⚠️ *Звонок переведён на вас*

Клиент: +7 916 555-01-23
Причина: несогласие с ценой
Длительность разговора: 2 мин

[Прослушать запись] [Позвонить клиенту]
```

#### Системное уведомление
```
✅ Алло снова активен
Был перерыв 3 минуты из-за проблем с подключением. Сейчас всё работает.

[Открыть дашборд]
```

#### Ежедневная сводка (опционально, в 21:00)
```
📊 *Итоги дня*

📞 Принято звонков: 8
✂️ Записалось: 5 (62%)
⚠️ На вашем контроле: 1
📅 Завтра записей: 3

Спокойной ночи! 🌙
```

### 5.4 Кнопки (Inline Keyboard)

Максимум 2 ряда кнопок, 2-3 кнопки в ряду.
Пример:
```
[📊 Статус] [📅 Записи] [📞 Звонки]
[⚙️ Настройки]
```

Ссылки на админ-панель — Web App или просто ссылки.

### 5.5 Стиль сообщений

- Markdown-форматирование: **жирный** для заголовков, `_курсив_` для акцентов
- Максимум 5 строк текста (длинные сообщения не читают)
- Эмодзи как визуальные маркеры, не спам
- Всегда кнопка действия (не просто информация)
- Ссылки на админку — короткие (через t.me/… или кнопка Web App)

### 5.6 Анти-спам

- Уведомления о записях — только если запись новая (не дублировать)
- Эскалации — сразу, без задержки
- Системные — не чаще 1 раза в час, если проблема не критическая
- Нет уведомлений ночью (22:00–09:00), если это не эскалация

## 6. Empty States

### Система пустых состояний

Каждый раздел должен иметь три градации пустоты:

#### 1. Нет данных (никогда не было)
Иконка + спокойный текст + кнопка действия (если применимо).

#### 2. Нет данных за период
«За сегодня звонков не было» — появляется, если данные есть, но не за выбранный период.

#### 3. Ошибка загрузки
«Не удалось загрузить данные. Проверьте подключение к интернету» + кнопка «Повторить».

### Иконки для пустых состояний (рекомендации Lucide)
- **Дашборд:** `BarChart3`
- **Звонки:** `PhoneOff`
- **Записи:** `CalendarX`
- **Настройки:** `Settings` (с восклицательным знаком)

### Цвет иконок для пустых состояний
- Primary 200 (только контур, 50% прозрачность)
- Размер: 64×64px

### Текст
- Заголовок: h3 (18px, 600)
- Описание: Body (16px, 400, Text Secondary)
- CTA: Secondary кнопка (если есть действие)

## 8. Loading & Error States

### 8.1 Loading States

| Страница | Тип загрузки | Детали |
|----------|-------------|--------|
| Дашборд | Skeleton | 4 прямоугольника для метрик + 1 большой для графика |
| Список звонков | Skeleton | 5 строк с текстом разной длины |
| Список записей | Skeleton | 3 карточки с иконкой, текстом |
| Настройки | Skeleton | 4 блока с текстом |
| Детали звонка | Spinner | Центрированный на всю высоту |
| Onboarding | Spinner + текст | «Загружаем данные...» |

### 8.2 Error States

| Сценарий | Поведение | Действие |
|----------|-----------|----------|
| Ошибка сети | Toast «Нет соединения с интернетом» + retry на странице | Кнопка «Повторить» |
| Ошибка сервера | Toast «Что-то пошло не так» + fallback | «Попробовать снова» |
| YClients недоступен | Предупреждение в настройках | «Подключиться позже» |
| Ошибка загрузки звонков | Empty state с триггером | «Повторить загрузку» |

### 8.3 Offline State

- Если админ-панель не может загрузиться → показать кэшированные данные (localStorage/Service Worker как improvement)
- Если данных нет в кэше → экран «Нет соединения» с иллюстрацией

## 9. Implementation Notes

### 9.1 Технологии (рекомендация)

- **Frontend:** React / Next.js или Vue 3 + Nuxt
- **UI Library:** Tailwind CSS + Headless UI / Radix UI (без готовой дизайн-системы)
- **Form:** React Hook Form + Zod
- **Charts:** Recharts (простые графики, не перегруженные)
- **Icons:** Lucide React
- **Telegram Bot:** node-telegram-bot-api или Telegraf
- **PWA:** Да, чтобы можно было «добавить на главный экран»

### 9.2 Доступность (WCAG 2.1 AA)

- Все кликабельные элементы должны иметь focus ring
- Alt-тексты для всех иконок и иллюстраций
- Цвет не единственный индикатор статуса (текст + иконка + цвет)
- Keyboard navigation: Tab, Enter, Space, Escape
- Screen reader labels на русском

### 9.3 Производительность

- Первый экран (LCP) < 2.5s на 3G
- Все списки — виртуальный скролл (react-window / @tanstack/virtual) при > 50 элементах
- Аудиозаписи — lazy load, не грузить все сразу
- Skeleton вместо спиннеров для контентных страниц
- Кэширование списков мастеров и услуг (редко меняются)

### 9.4 Локализация

- MVP: только русский
- i18n подготовка: все строки через функции перевода (чтобы не переписывать потом)
- Форматы: даты «15 мая 2024», время «14:30», телефон «+7 916 555-01-23»

### 9.5 Избранная анимация

- **Page transitions:** fade + slide up (200ms, ease-out)
- **Modal open:** scale(0.95 → 1) + fade (200ms)
- **Bottom sheet:** slide up (300ms, cubic-bezier)
- **Hover:** scale(1.02) на карточках (200ms)
- **Toggle:** slide (200ms)
- **Notification badge:** scale pulse (300ms)
- **Skeleton shimmer:** 1.5s loop

Все анимации: `prefers-reduced-motion: reduce` → отключаем.

### 9.6 Dark Mode

- Переключатель в настройках (светлая / тёмная / как на устройстве)
- `prefers-color-scheme` для автоматического определения
- Сохраняем выбор в localStorage

## Приложение B: User Flows

### B.1 Первый вход (Onboarding)

```
Вход → Проверка: прошёл онбординг?
  ├─ Нет → Onboarding Wizard Шаг 1 (приветствие)
  │        → Шаг 2 (номер телефона)
  │        → Шаг 3 (YClients / без CRM)
  │        → Шаг 4 (приветствие + тон)
  │        → Экран успеха → Дашборд (пустой)
  └─ Да → Дашборд (с данными или пустой)
```

### B.2 Просмотр звонка

```
Список звонков → Тап на звонке → Bottom Sheet
  ├─ Данные загружены → Аудио + расшифровка + результат
  │   └─ Тап «Слушать» → Аудио плеер
  │   └─ Тап «Скачать» → Скачивание аудио
  │   └─ Тап «Редактировать» → Экран редактирования записи
  └─ Ошибка → Toast «Не удалось загрузить» + Retry
```

### B.3 Уведомление Telegram → Действие

```
Новая запись → Уведомление в Telegram
  ├─ Тап «Посмотреть в админке» → Web App / браузер
  │   → Страница записи (авторизация уже есть)
  └─ Игнор → Ничего, запись сохранена
```

### B.4 Эскалация звонка

```
Клиент жалуется / хамит → Алло переводит на владельца
  → Telegram уведомление: «Звонок переведён на вас»
  → Владелец тапает «Позвонить клиенту» → набор номера
  → Или «Прослушать запись» → аудио диалога
```
